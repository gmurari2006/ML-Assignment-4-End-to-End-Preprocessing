# ML Assignment 4 — End-to-End Preprocessing

## 📌 Project Overview

This project implements an end-to-end data preprocessing workflow using the **Hotel Booking Dataset**.

The purpose of this assignment is to demonstrate how a raw real-world dataset can be transformed into a clean, validated, feature-engineered, and machine-learning-ready dataset.

The complete workflow includes:

- Dataset loading
- Initial data inspection
- Missing-value analysis
- Duplicate detection
- Data-quality validation
- Invalid-value detection
- Data cleaning
- Outlier handling
- Feature engineering
- Target separation
- Train-test splitting
- Numerical preprocessing
- Categorical encoding
- Feature scaling
- Feature selection
- Preprocessing pipeline creation
- Pipeline serialization
- Final verification

The entire workflow was implemented in **Python using Pandas and Scikit-learn in Google Colab**.
